# 0.7.0 候选验收

适配 DSH 0.2.1-rc.5，macOS arm64。Node 24.16.0、pnpm 10.33.2；新增官方 @codemirror/search 6.7.2，依赖固定在 pnpm-lock.yaml，未更换工具链。

本轮覆盖增量实时预览、轻量文件变化检测、普通文档恢复、阅读位置、格式/查找快捷键和当前文档大纲。自动测试包含与完整渲染差分、连续编辑、重复标题、元数据/代码排除、恢复容量、不同窗口隔离和中文组合保存状态。

实际独立 DSH 界面验证了大纲跳转、多层正文折叠展开、重复标题、长文档及超过 20 万字符文档的后台大纲、恢复保存和位置记忆。390 CSS px 布局检查目录与正文切换、查找和横向溢出。原生 WebKit 测试使用系统拼音输入法，检查候选保留、退格修正、选词、Tab、换行、加粗切换和查找框候选取消，并逐字读回草稿及测试 Inbox。

性能测量使用固定混合 Markdown 夹具，对比原实现与候选的 EditorState.update 耗时，包含实时预览状态计算，不包含原生事件排队、DOM 布局或屏幕绘制。不能将这项结果称为端到端输入时延。

全部使用临时文档、草稿和 Inbox。原生隔离窗口禁用全局快捷键注册，避免与正式宿主争用。源码、制品、隔离 Loader、正式 Desktop 及用户体感分别验收；本页不代表已在所有设备或网络条件通过。最新正式安装状态、制品摘要和原始性能样本保存在本次本机任务验收记录中，不放入公开包。

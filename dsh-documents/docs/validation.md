## 适用边界

结论限于上述环境和测试场景。未验证其他输入法、候选窗视觉位置、390px Web 窄布局、Desktop 最小窗口、浅色主题、真实 PDF/Office 展示、其他操作系统或跨设备云同步。当前浏览器控制关闭，未把旧 Web 截图当作本版窄布局证据。

本机保存成功不代表云同步完成。版本检查保护通常的外部修改，但没有跨设备文件锁、差异合并或版本历史。页面重载或插件卸载后不恢复尚未保存的草稿。

## 复现

进入 `dsh-documents/`，使用声明的工具链执行 `pnpm install --frozen-lockfile --ignore-scripts`、`pnpm test`、`pnpm build` 和 `pnpm pack`。在独立 `DSH_HOME`、`DSH_AGENTS_HOME` 和完整 Web profile 安装制品，不复制账户配置或私人文档。正式安装包和 `SHA256SUMS` 由对应插件版本的 Release 提供。

# 0.8.0 候选验收

[English](validation-0.8.0.en.md)

日期：2026-11-04。宿主 DSH 0.2.1-rc.5、macOS arm64；Node 24.16.0、pnpm 10.33.2，未新增依赖或改动锁文件。

## 已覆盖

- 90 项自动检查通过。旧解析器丢失编码中文标题片段的场景先失败、修正后通过；标题层级、格式标题、重复标题顺序、访问历史分支/边界、YAML 原文、表格行列/管道符/反斜杠均有行为检查。
- 独立 DSH_HOME / Web profile 加载实际插件。中文标题链接和父子标题路径正确定位，后退/前进返回对应文档与位置；编辑器数量保持一个。
- 属性默认折叠，可展开多行原值；没有 YAML 重写或外部请求。测试嵌套字段和注释原文保留。
- 表格点击单元格输入、Tab/Shift+Tab、增删行列、撤销和自动保存通过。单表只创建一个轻量文本框，读写仍使用共享编辑器和版本校验。
- 原生 WebKit 临时随记使用系统中文拼音输入：全选、候选保留、空格提交、组合内退格修正通过；未提交拼音不落盘。普通跨格和末尾追加行的 Tab、Shift+Tab、Escape 验证通过。Mac 系统撤销可还原增列。
- 原生测试的中文单元格逐字读回匹配，每份提交只出现一次，提交后草稿清空；属性和正文原文保留。临时原生窗口未注册全局快捷键，结束后 dispose。

## 修正过的问题

初版使用嵌套 contenteditable 单元格，原生操作中焦点可能回到正文。已改为轻量 textarea，并在跨格移动期间隔离 blur 清理；系统 beforeinput 的撤销/重做也接入共享编辑器。失败输入不计为通过，修正版重新进行原生验证。

性能样本只测 EditorState.update，包括预览状态更新，不包含 DOM、原生事件排队或屏幕绘制。不能将其作为端到端按键延迟。源码、构建、包内文件、隔离安装与可见行为分别核对；正式安装状态以本地交付记录为准。

## 范围与限制

不提供块引用定位、完整 YAML 类型编辑、二维表格粘贴、排序、公式、合并单元格或版本历史。超限/复杂表格可继续源码编辑。历史仅保留当前面板最多 50 个路径/位置，不保存正文。

候选未发布 GitHub。本轮只使用临时夹具，不修改正式笔记、Inbox 或随记草稿；正式 Desktop 仍需单独安装和验收。

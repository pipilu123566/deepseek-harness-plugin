# 0.7.1 设置与导航验收

[English](validation-0.7.1.en.md)

日期：2026-11-04。宿主：DSH 0.2.1-rc.5，macOS arm64。Node 24.16.0、pnpm 10.33.2，沿用锁文件，无新增依赖或工具链降级。

## 已验证

- 82 项现有自动检查通过，构建成功。
- 独立 DSH_HOME、无真实凭据的 Web profile 使用打包制品加载；仅使用示例文档和 Inbox，全局快捷键关闭。
- 左侧导航包含侧栏开关、文件与大纲。底部齿轮打开独立设置页，文档顶部不再展示 Inbox、随记或配置按钮。
- 设置页分为文档库、Inbox、附件、随记和关于；可打开固定 Inbox、打开随记、保存配置。未保存配置修改时，打开 Inbox／随记按钮禁用，保存或取消后恢复。
- 设置页打开后聚焦首个输入框；返回原文档保留光标和滚动，撤销仍有效，原文档只有一个编辑器。
- 从设置打开随记后，可提交到测试 Inbox；正文读回匹配，提交后草稿清空。关闭随记返回原文档。
- 侧栏收起后保留 40px 图标列，设置、大纲与文件入口仍可操作。
- 正文工具栏重复的大纲按钮已移除。左侧大纲跳转与编辑焦点恢复通过。
- 深色与浅色设置页实际截图已检查。390×844 Web 窄屏下导航和设置可达，无横向溢出；大纲跳转后编辑焦点正确。

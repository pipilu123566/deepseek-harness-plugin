# 0.4.0 本地候选验收

日期：2026-11-02。目标宿主 DSH 0.2.1-rc.5，macOS arm64；项目构建使用 Node 24.16.0、pnpm 10.33.2。

## 范围

文档、固定 Inbox、网页随记与 Mac 全局随记使用同一份 CodeMirror 编辑与随记实现。全局随记仅增加宿主内 WebKit 窗口，不启动独立常驻应用或 HTTP 服务。

## 证据

- 37 项行为检查：Tab/反缩进/撤销、中文组合保存暂停、候选键与 Escape 焦点退出、Markdown 原文与双链显示、同名歧义、根目录限制、附件复制、草稿重载、追加去重、版本冲突、中断恢复与 BOM/CRLF、旧草稿只复制一次。
- 实际 tarball 安装至独立 Web profile，真实 Loader 注册服务；认证 RPC 写入和回读 SQL、拒绝过期版本保存与越界路径。配置、日志和测试文档与日常 profile 分开。
- Chrome：文件树与实时预览、正文 Tab、多行与列表缩进、Shift+Tab、Escape 后 Tab、会话全文/选段引用到输入框而不发送；1280×820 与 390×844 布局；选择附件、图片显示、草稿刷新恢复。
- 独立原生窗口承载实际同源编辑器：真实 Tab 与反缩进、Escape 后 Tab 移到工具栏；系统拼音组合状态与候选选择，组合期间不保存拼音串，提交后回读中文；附件选择、相对 Markdown 引用和图片显示；选择器打开时卸载能取消并释放窗口与回调。
- 正式 Desktop 已安装候选并保留原根目录和 Inbox；旧速记停用但数据未删除。全局快捷键在隔离环境完成真实人工触发：用户确认浮窗出现，宿主回读触发计数为 1。正式 Desktop 的最终安装回读与此项分开记录。

## 限制

- 未覆盖所有输入法、第三方输入法、真实手机/iPad、跨网络编辑与其他操作系统。窄屏浏览器结果不等于真实设备验收。
- 正式公网入口本次访问超时，不能据此声称跨网络访问通过；本机独立 Web 编辑链路已验证。
- 普通文件的失败草稿保留在当前窗口；随记草稿单独落盘。多个随记窗口同时修改同一草稿时拒绝旧版本，不自动合并。
- 本地候选尚未发布到 GitHub；0.3.0 的 Release 与演示仍保持原版本。

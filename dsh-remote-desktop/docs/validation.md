# 验收范围

中文 | [English](validation.en.md)

本记录对应远程桌面 0.4.2，目标宿主 DeepSeek Harness 0.2.1-rc.5。被控端为 Apple Silicon Mac、macOS 13+；电脑端浏览器的按键映射不代表支持 Windows/Linux 被控端。最终提交、tag、安装包 SHA-256 和公开下载复验结果见本版 Release。

## 本版功能与测试

- 显示器、画质及连接详情移入顶部菜单栏；手机访问通过右上角图标打开浮窗，关闭或页面后台清除本页链接与二维码。
- 删除原独立快捷输入区及按钮，保留已有直接键盘输入，没有新增输入法通道或改动系统密码处理。
- 普通滚轮滚动远端，Shift+滚轮横向滚动，Ctrl/⌘+滚轮缩放；移动画面模式下滚轮和拖动平移。
- 自动模式在 Windows/Linux 客户端映射 Ctrl/Windows 修饰键到 Mac Command/Control，Mac 客户端原样传递；另可手动选 PC 或原样模式。原样适用于终端 Ctrl 组合键；系统/浏览器保留键未必能转发。
- 修复 Desktop 热更新时语言字典未清理导致侧栏入口丢失，保留对旧页面残留字典的一次性迁移。

27 项自动检查覆盖键鼠映射、两项浮窗事件、两项客户端重复挂载、认证、权限、独占连接、信令/输入隔离、取消清理、输入合并和触摸缩放几何。另有三项实际 app.js 事件回放（PC Ctrl+C、Shift+滚轮、⌘+滚轮）通过；回放的 DOM/DataChannel 是替身，不冒充真实设备输入。

最终安装包须从固定提交的干净检出生成，逐文件比对提交，验证隔离 Loader、所有者登录、静态资源、未授权拒绝、卸载后 404 和重装，再匿名下载本版附件校验并在另一全新 profile 安装。对应结果与制品校验值登记在 Release，不以本机源码链接安装代替公开包验收。

## 实机证据

2026-11-01，用户重新加载并检查顶部控件、快捷输入移除及另一台电脑键鼠，反馈「布局和电脑键鼠都正常」。直接输入原本可用，本次不称为修复输入故障。客户端设备、系统与浏览器明细未记录，不代表所有组合已覆盖。此前用户已确认手机连接、操作、断开、双指缩放、双屏操作与流畅优先改善。

侧栏修复已在目标宿主的真实 LocaleRuntime 重复挂载复验，并在维护用 Desktop 的重复热更新后保留单一入口。上述实机证据对应本版运行代码；文档/包元数据更新不等于重新进行整套设备测试。

## 原生助手与历史性能

0.4.2 复用未变的 0.4.1 原生助手，解压前校验压缩包 SHA-256，运行前验证应用签名。画质、认证、租约和唤醒策略未改。

0.4.1 的本机 Chrome 样本收到清晰优先 2940×1912、流畅优先 2214×1440，两种模式切换成功；约 29/30 FPS、69/22ms 接收缓冲和 4/1ms 网络往返属于当时本机样本，不是手机端到端延迟承诺。此前限速队列回放验证合并旧移动事件并可靠松键，不能据此保证任意网络性能。

## 限制与展示来源

真实 iPad、全部客户端/网络组合、TURN 中继、整机唤醒、锁屏密码输入与解锁及系统安全输入仍未逐项验收。普通输入成功不等于支持 Touch ID 或 FileVault 重启前解锁。助手为临时签名、未做 Apple 公证，每台 Mac 须完成自己的录屏与辅助功能授权。无声音、文件传输或跨设备剪贴板同步。

首页 0.4.2 图片是中英文操作流程示意，不是界面实录。以 AI_Animation 的 dynamic-archify 工作流布局生成 SVG，再离线栅格化为 PNG；两种语言均已查看。0.4.1 界面图和 0.3.6 动图明确保留为历史材料，不冒充新版截图。发布时对公开媒体字节及 README 入口回读；未把浏览器不可用时的 HTTP 检查算作 GitHub 页面视觉验收。

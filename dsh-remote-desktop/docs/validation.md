# 验收范围

中文 | [English](validation.en.md)

0.3.6 为首次公开预览版，基于本机 0.3.5 整理。Host、Client、网页、输入协议和原生助手沿用原实现；变化为公开元数据、许可、中英文说明、独立源码目录和脱敏部署模板。原生助手移除包含本机路径的调试符号后重新临时签名，可执行代码段保持一致。本机正在运行的 0.3.5 不因公开发布而被替换。

## 已有功能证据

- DSH 0.2.1-rc.5、Apple Silicon Mac 上，真实桌面曾收到 1920×1080 视频；中文、特殊字符、合成测试密码及鼠标点击由 Mac 测试窗口确认。断开和重连成功。
- 用户已确认手机连接、操作、断开，以及 0.3.3 的加减按钮和双指放大、缩小；浏览器归类为微信或其他应用内浏览器，具体机型及网络未记录。
- 390×844 和 820×1180 视口检查属于浏览器模拟；不等于真实 iPad 验收。
- 0.3.5 在同一锁屏 Mac 上复现显示器休眠采集失败，唤醒后启动 1920×1080 采集；专用助手与唤醒保持在断开后退出。该修复后的手机完整复测仍待用户确认。

## 公开版本检查

13 项项目检查覆盖认证、权限、单连接、信令与输入隔离、旧连接清理、缩放锚点和坐标、显示器唤醒顺序、断开和取消清理。发布前从固定提交打包，核对制品与 Git 源码；用隔离 DSH_HOME/profile 安装并验证真实 Loader、所有者登录、受保护 API、网页资源、卸载和重装。正式 Release 的提交、SHA-256 及公开下载复验结果以 Release notes 为准。

## 未验证与限制

真实 iPad、各浏览器和不同网络、TURN 中继、整机睡眠唤醒、锁屏密码输入与解锁、系统特殊安全输入尚未逐项验收。普通密码框成功不代表 Touch ID 或 FileVault 解锁可用。原生助手为临时签名，未公证；需要在目标 Mac 单独完成系统授权。

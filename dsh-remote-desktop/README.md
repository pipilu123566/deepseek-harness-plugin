# DSH 远程桌面

中文 | [English](README.en.md)

通过电脑、手机或 iPad 的浏览器查看和操作 Mac，支持直接键盘输入、鼠标滚轮和双指缩放平移。独立社区插件，不调用模型，不暂停或继续 AI 任务。

**0.4.2 公开预览版**，兼容 DeepSeek Harness **0.2.1-rc.5**。电脑端仅支持 **Apple Silicon Mac、macOS 13 及以上**。目前网页和 Mac 权限窗口主要使用中文。

## 安装

从 [0.4.2 Release](https://github.com/pipilu123566/deepseek-harness-plugin/releases/tag/%40pipilu%2Fdsh-remote-desktop%400.4.2) 下载 `pipilu-dsh-remote-desktop-0.4.2.tgz` 和 `SHA256SUMS`。在两份文件所在目录运行 `shasum -a 256 -c SHA256SUMS`。

在 DeepSeek Harness 的插件管理中选择下载的 `.tgz` 并启用。Web CLI 可在目标 Web profile 中安装本地包：

```sh
dsh plugin --profile <你的 Web profile> add /绝对路径/pipilu-dsh-remote-desktop-0.4.2.tgz --ignore-scripts
```

安装后从侧栏打开「远程桌面」。仓库根目录不是插件；包名仍为 `@pipilu/dsh-remote-desktop`，本版不发布到 npm。

## 显示器与画质模式

画质只保留「流畅优先」和「清晰优先」，显示器独立选择。流畅优先默认以最高 1440p 采集，WebRTC 优先保持帧率，负载或网络吃紧时可降低实际传输分辨率；清晰优先按原生像素采集，最高 3840×2160，并优先保留分辨率，必要时降低帧率。二者均保持比例、不放大超过原生像素，不修改 Mac 本地显示模式。切换模式或显示器会自动重连。

高频鼠标移动和滚动在浏览器按帧合并，点击、松键、快捷键和文字保持可靠传输；严重拥堵时安全断开，不静默丢弃松键。采集队列为两帧，过期画面不追赶。展开「连接状态」可查看实际接收尺寸、网络往返、输入确认往返、接收帧率及视频缓冲。这些数值不是完整的点击到画面响应延迟；静态画面帧率可能自然降低。

用户已在手机确认流畅优先明显改善、可正常使用。清晰优先在当前手机网络下的延迟仍待单独确认；不同设备与网络的效果需要各自验证。

## 从旧版升级

使用 0.4.2 `.tgz` 更新同名插件并启用，再重新加载远程桌面网页。新版包含 0.4.1 的两种画质，并修复 Desktop 热更新时语言字典残留导致的侧栏入口消失。旧的独立快捷输入区和按钮已移除，直接点击目标后使用键盘；手机访问改在顶部右侧的手机图标中打开。

原生助手继续使用 0.4.1 制品，未重编或改动采集策略。升级时保留现有配置；不要为测试升级卸载其他插件。

## 连接和操作

1. 在 Mac 上运行 DeepSeek Harness。首次使用点击「在 Mac 设置权限」，完成屏幕录制与辅助功能授权，再刷新状态。系统设置中的权限归属可能显示为 DeepSeek Harness。
2. 点击「连接这台 Mac」。点按电脑画面中的目标位置后，可以拖动、滚动和直接使用键盘。直接输入方式保留，新版移除原来的「快捷输入」区及其按钮；不会自动输入或保存登录密码。
3. 手机首次访问时，在已登录的页面点击顶部栏右侧的手机图标，打开「在手机或 iPad 上打开」浮窗，准备二维码或复制本人完整登录链接，在手机浏览器打开。二维码在本地生成，60 秒后或切换后台时清除；清除二维码不会撤销已签发的 DSH 所有者授权。登录链接拥有 DSH 所有者访问权，不应转发。
4. 双指张合连续缩放，范围为适应屏幕的 1–8 倍。放大后双指平移；开启「移动画面」可单指平移。适应屏幕时双指滚动电脑内容。下方「−」「＋」「适应屏幕」提供按钮操作和复位；旋转设备后保留缩放倍数。
5. 操作结束点击「断开连接」，或在 Mac 菜单栏的「远控」中断开。断开只结束远控，不关闭 Mac 或其他应用。

普通网址不自带授权。微信内浏览器、Safari 和 Chrome 的登录状态可能不共享，更换浏览器后应在同一浏览器打开完整登录链接。未授权访问显示设备授权指引，API 仍拒绝匿名请求。Host 重启后旧登录链接可能失效，需要重新生成。

## 紧凑布局与电脑操作

显示器切换、画质和连接详情已移入顶部菜单栏，窄屏时在该栏内换行；设备名和连接状态保持紧凑，画面使用剩余窗口高度。手机图标仍在顶部右侧，点击打开本人链接与二维码浮窗。关闭浮窗清除当前页面的链接与二维码，不撤销已签发授权。旧的快捷输入区及按钮已移除，直接点选远程目标后使用键盘；本轮没有新增输入法或密码处理通道。

| 电脑操作 | 结果 |
| --- | --- |
| 滚轮 | 滚动远端内容 |
| Shift + 滚轮 | 横向滚动；浏览器已转换的横向增量不重复转换 |
| Ctrl / ⌘ + 滚轮 | 围绕鼠标位置缩放画面 |
| 开启「移动画面」后拖动或滚轮 | 平移画面 |
| Windows / Linux 的 Ctrl 组合键 | 自动模式对应 Mac ⌘；Mac 客户端原样传递 |

在页脚「操作提示」可选择自动、PC Ctrl → Mac ⌘ 或原样传递。终端需要原生 Ctrl+C 等组合时选择原样传递。复制/粘贴作用于 Mac 上的剪贴板；这不是跨设备剪贴板同步。浏览器或系统保留的快捷键可能无法转发。手机和 iPad 保留点按、双指缩放、平移和滚动。

本版的 27 项自动检查通过，覆盖键鼠映射、浮窗、客户端生命周期和既有远控逻辑；用户已确认「布局和电脑键鼠都正常」。具体设备、系统和浏览器组合未记录，不代表所有客户端均已验证。新版安装包的提交、校验值和隔离安装结果见 Release 与[验收记录](docs/validation.md)。

## 手机和外网访问

插件不会自动开通公网服务。手机必须能访问运行插件的 DSH HTTPS 入口；仅在 Mac 回环地址运行的页面不能直接从手机访问。公网部署使用自己的域名、HTTPS 反向代理或隧道，保留 DSH 所有者认证、原始 `Host` 和 `Origin`，不要直接公开无认证的本地端口。部署说明见 [HTTPS 与中继配置](docs/deployment.md)。

默认使用 STUN 尝试 WebRTC 直连。HTTPS 隧道只承载网页和信令，不等于 TURN 媒体中继；无法直连的网络可能需要配置自己的 `iceServers`。当前不提供 TURN 账号或中继服务。

## 支持范围与已知限制

| 项目 | 范围 |
| --- | --- |
| 被控电脑 | Apple Silicon Mac、macOS 13+；Intel Mac、Windows、Linux 被控端未支持 |
| 画面 | 可切换当前连接的显示器，最高 3840×2160（不超过原生像素），采集目标 30 fps；无音频或文件传输 |
| 输入 | 鼠标、快捷键、Unicode 文字与普通密码框；不承诺所有系统安全输入场景 |
| 移动端 | 用户已确认手机连接、操作、断开、双指缩放、双屏操作和流畅优先改善；真实 iPad、所有浏览器和不同网络尚未逐项验证 |
| 睡眠与锁屏 | 连接前唤醒显示器，会话期间保持屏幕和系统唤醒，断开后释放；整机休眠唤醒、锁屏密码输入与解锁仍待验证 |
| 原生助手 | 随包提供 0.4.1 助手，解压时校验 SHA-256 和应用签名；本地临时签名，未做 Apple 公证 |

Mac 必须保持开机、联网并运行 DeepSeek Harness。显示器唤醒不取消系统锁屏，不支持 FileVault 重启前解锁或替代 Touch ID。0.3.5 已在锁屏 Mac 验证休眠显示器唤醒后能启动采集，尚未收到该修复后的手机完整复测结果；不能据此认定锁屏画面和密码输入均可用。

## 实现与数据

ScreenCaptureKit 采集 → WebRTC 视频 → 浏览器；键鼠和文字经 WebRTC DataChannel 发送，由 Mac 的 CGEvent／辅助功能执行。DSH Host 负责所有者认证和单连接租约，原生助手通过子进程标准输入／输出管理，没有新增本地 TCP 控制端口。原生实现不依赖 macOS 屏幕共享。

连接状态仅保存在内存，未建立通道的预约 15 秒后释放。信令只允许 SDP 和 ICE；文字、密码和桌面画面不写入聊天或插件诊断日志。主动断开、通道关闭或插件停止时释放输入状态并结束对应助手和唤醒保持进程。插件不持久保存输入或录制桌面；DSH 自身的认证 Cookie 由宿主管理。

## 开发与构建

使用 Node **22.21.1**、pnpm **10.33.2** 和本目录的锁文件。在插件目录运行：

```sh
pnpm install --frozen-lockfile --ignore-scripts
pnpm test
pnpm build
pnpm pack --pack-destination /绝对路径/输出目录
```

仓库包含已签名助手压缩包，日常网页修改不需要重编原生助手。重编需要 macOS、Swift **6.3.3**（Swift tools 5.10 模式）：先按 `native/vendor-lock.json` 下载 WebRTC **156.0.0**，核对 SHA-256，将 XCFramework 解压为 `native/Vendor/WebRTC.xcframework`，再运行 `pnpm build:agent`。此命令更新助手压缩包、临时签名及清单哈希。

27 项测试覆盖认证、权限、租约、信令隔离、断开清理、唤醒期间取消、缩放坐标、模式选择与输入合并。发布验收与尚未覆盖的场景见 [验收记录](docs/validation.md)。
